# Status do produto

**Referência documental:** 16/11/2026, conforme os arquivos disponíveis no repositório de desenvolvimento na data da preparação desta vitrine. O status pode evoluir.

## Implementação

O projeto contém código e documentação para dashboard, estoque, caixa/vendas, rifas, reservas, prêmios, sorteios, pagamentos, retiradas, histórico e integração local opcional com grupos do WhatsApp.

## O que ainda precisa ser concluído para distribuição

- Preparação e homologação do **instalador completo**, inclusive banco Firebird, para máquinas novas.
- Testes de instalação, atualização, encerramento/reabertura e recuperação de falhas em ambiente limpo.
- Revisão operacional de ponta a ponta dos fluxos de uso em ambiente de cliente.
- Revisão de dependências e riscos do conector não oficial de WhatsApp.

## O que esta vitrine não promete

- Instalação imediata ou disponibilidade de versão pública para download.
- Integração oficial com WhatsApp/Meta.
- Pagamento automático via PIX ou confirmação automática de recebimentos.
- Uso distribuído em múltiplos computadores sem projeto de implantação específico.
- Licença para redistribuição do software.

A disponibilidade de demonstração ou implantação deve ser confirmada com o responsável pelo projeto.
